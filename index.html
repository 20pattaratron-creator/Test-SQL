Calculated Fields ที่ใช้บ่อย

          
Net Sales = [Quantity] * [Unit Price] * (1 - [Discount])
Gross Sales = [Quantity] * [Unit Price]
Total Cost = [Quantity] * [Cost]
Profit = [Net Sales] - [Total Cost]
Profit Margin = IF SUM([Net Sales]) = 0 THEN 0 ELSE SUM([Profit]) / SUM([Net Sales]) END
Order Month = DATETRUNC('month', [Order Date])
AOV = SUM([Net Sales]) / COUNTD([Order ID])
Customer Type = IF { FIXED [Customer ID] : COUNTD([Order ID]) } >= 2 THEN "Repeat" ELSE "One-time" END

DAX Measures ที่ใช้บ่อย

          
Gross Sales = SUMX(orders, orders[quantity] * orders[unit_price])
Discount Amount = SUMX(orders, orders[quantity] * orders[unit_price] * orders[discount])
Net Sales = SUMX(orders, orders[quantity] * orders[unit_price] * (1 - orders[discount]))
Total Cost = SUMX(orders, orders[quantity] * orders[cost])
Profit = [Net Sales] - [Total Cost]
Profit Margin = DIVIDE([Profit], [Net Sales], 0)
Total Orders = DISTINCTCOUNT(orders[order_id])
Total Customers = DISTINCTCOUNT(orders[customer_id])
Average Order Value = DIVIDE([Net Sales], [Total Orders], 0)
Order Month = FORMAT(orders[order_date], "YYYY-MM")
MoM Growth = DIVIDE([Net Sales] - CALCULATE([Net Sales], DATEADD('Calendar'[Date], -1, MONTH)), CALCULATE([Net Sales], DATEADD('Calendar'[Date], -1, MONTH)), 0)

        

        

          
Power Query / M ตัวอย่างสำหรับเตรียมข้อมูล

          
let
    Source = Csv.Document(File.Contents("sample_sales.csv"), [Delimiter=",", Encoding=65001, QuoteStyle=QuoteStyle.Csv]),
    PromotedHeaders = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    ChangedTypes = Table.TransformColumnTypes(PromotedHeaders, {
        {"order_date", type date}, {"quantity", Int64.Type}, {"unit_price", type number}, {"discount", type number}, {"cost", type number}
    }),
    AddedNetSales = Table.AddColumn(ChangedTypes, "net_sales", each [quantity] * [unit_price] * (1 - [discount]), type number),
    AddedTotalCost = Table.AddColumn(AddedNetSales, "total_cost", each [quantity] * [cost], type number),
    AddedProfit = Table.AddColumn(AddedTotalCost, "profit", each [net_sales] - [total_cost], type number)

SPSS Helper สำหรับผู้เริ่มต้น

            
ส่วนนี้ช่วยให้ผู้ใช้ที่ไม่เคยใช้ SPSS เข้าใจตั้งแต่การเตรียมไฟล์ CSV/Excel, Data View, Variable View, การกำหนดชนิดตัวแปร, การตรวจข้อมูล และการเลือกสถิติให้ตรงคำถาม

          

          ดาวน์โหลด SPSS Syntax
        

        

          

            
1

            
เตรียมไฟล์จากระบบนี้

            
Export CSV จาก Dashboard / SQL Result / Table Browser แล้วนำไฟล์ไปเปิดใน SPSS ด้วยเมนู File > Import Data > CSV หรือ Excel

          

          

            
2

            
ตั้งค่า Variable View

            
กำหนด Type, Label, Values, Missing และ Measure ให้ถูกต้อง เช่น customer_id เป็น Nominal, satisfaction เป็น Ordinal, net_sales เป็น Scale

          

          

            
3

            
เลือกสถิติให้ตรงคำถาม

            
ใช้ Frequencies/Descriptives เพื่อดูภาพรวม, Crosstabs เพื่อดูความสัมพันธ์ตัวแปรกลุ่ม, Correlation/Regression เพื่อดูความสัมพันธ์เชิงตัวเลข

          

        


        

          

            
Excel → SPSS สำหรับคนเริ่มต้น

            
เพิ่มไฟล์ตัวอย่าง Excel พร้อม Codebook และ Checklist เพื่อให้ผู้ใช้เห็นโครงสร้างตารางที่เหมาะกับ SPSS ก่อนนำเข้าข้อมูลจริง

          

          

            ดาวน์โหลด Excel Template
            ดาวน์โหลดคู่มือ Excel → SPSS
          

        


        

          
หลักการทำงานของ SPSS จาก Excel

          
    
            
  1. Excel เป็นแหล่งข้อมูล: แถวแรกควรเป็นชื่อตัวแปร เช่น customer_id, net_sales, profit และข้อมูลเริ่มที่แถว 2
    2. 
            
  2. Data View คือข้อมูลจริง: เมื่อ Import แล้ว SPSS จะแสดงตารางเหมือน Excel โดย 1 แถวคือ 1 record
    3. 
            
  3. Variable View คือคำอธิบายข้อมูล: ต้องตรวจ Type, Label, Values, Missing และ Measure ก่อนวิเคราะห์
    4. 
            
  4. Value Labels ช่วยแปลรหัส: เช่น gender เป็น 1=ชาย, 2=หญิง หรือ use_in_analysis เป็น 1=ใช้, 0=ไม่ใช้
    5. 
            
  5. Measure ต้องถูกต้อง: กลุ่มข้อมูลใช้ Nominal, ระดับ/อันดับใช้ Ordinal, ตัวเลขต่อเนื่องใช้ Scale
    6. 
            
  6. Filter ข้อมูลผิด: ถ้าแถวไหนไม่ควรคำนวณ ให้ใช้ use_in_analysis = 1 ใน Data > Select Cases
    7. 
          

        


        

          
ตัวอย่างการตั้งค่าจาก Excel ใน Variable View

          

            

              
คอลัมน์จาก ExcelความหมายType ใน SPSSMeasureสิ่งที่ควรตั้งเพิ่ม

              
                
customer_idรหัสลูกค้าStringNominalLabel = รหัสลูกค้า

                
genderเพศNumericNominalValues: 1=ชาย, 2=หญิง, 3=อื่นๆ/ไม่ระบุ

                
satisfactionความพึงพอใจ 1-5NumericOrdinalValues: 1=น้อยที่สุด ... 5=มากที่สุด

                
categoryหมวดสินค้าStringNominalใช้ Frequencies หรือ Crosstabs

                
net_salesยอดขายสุทธิNumericScaleใช้ Descriptives / t-test / ANOVA / Regression

                
use_in_analysisใช้ในการวิเคราะห์หรือไม่NumericNominalValues: 1=ใช้, 0=ไม่ใช้ และใช้ Select Cases

              
            

          

        


        

          
เส้นทางใช้งาน SPSS แบบมือใหม่

          
    
            
  1. นำเข้าข้อมูล: File > Import Data > CSV/Excel แล้วเลือกไฟล์ที่ Export จากเว็บนี้
    2. 
            
  2. ตรวจ Data View: ดูแถวและคอลัมน์ว่าข้อมูลเข้า SPSS ครบหรือไม่
    3. 
            
  3. ตรวจ Variable View: เปลี่ยน Measure เป็น Nominal / Ordinal / Scale ให้เหมาะสมก่อนวิเคราะห์
    4. 
            
  4. กำหนด Missing: ถ้าข้อมูลมีรหัส 99, 999 หรือช่องว่างแทนคำตอบที่หาย ให้ตั้งเป็น Missing Value
    5. 
            
  5. เริ่มวิเคราะห์พื้นฐาน: Analyze > Descriptive Statistics > Frequencies หรือ Descriptives
    6. 
            
  6. วิเคราะห์ความสัมพันธ์: Crosstabs, Correlation หรือ Regression ตามชนิดตัวแปร
    7. 
            
  7. อ่านผลลัพธ์: ดูค่า N, Mean, Std. Deviation, p-value, R, R Square และ Sig. อย่างระมัดระวัง
    8. 
            
  8. บันทึกผล: Save เป็น .sav และ Export Output เป็น PDF/Word/Excel เพื่อแนบรายงาน
    9. 
          

        


        

          
เลือกเมนู SPSS ตามคำถามที่ต้องการตอบ

          

            

              
คำถามทางธุรกิจ/ข้อมูลเมนู SPSSใช้เมื่อไรผลลัพธ์ที่ควรอ่าน

              
                
ข้อมูลแต่ละคอลัมน์มีจำนวน/สัดส่วนเท่าไรAnalyze > Descriptive Statistics > Frequenciesตัวแปรกลุ่ม เช่น region, channel, categoryFrequency, Percent, Valid Percent

                
ยอดขาย/กำไรเฉลี่ยเท่าไร กระจายมากไหมAnalyze > Descriptive Statistics > Descriptivesตัวแปรตัวเลข เช่น net_sales, profitMean, Std. Deviation, Min, Max

                
ช่องทางขายสัมพันธ์กับสถานะคำสั่งซื้อไหมAnalyze > Descriptive Statistics > Crosstabsตัวแปรกลุ่ม 2 ตัวChi-square Sig., Row %, Column %

                
ยอดขาย Online กับ Store ต่างกันไหมAnalyze > Compare Means > Independent-Samples T Testตัวเลข 1 ตัว เทียบกลุ่ม 2 กลุ่มLevene's Test, Sig. (2-tailed), Mean Difference

                
ยอดขายต่างกันตามหลายภูมิภาคไหมAnalyze > Compare Means > One-Way ANOVAตัวเลข 1 ตัว เทียบกลุ่ม 3 กลุ่มขึ้นไปF, Sig., Post Hoc

                
ส่วนลดสัมพันธ์กับยอดขายหรือกำไรไหมAnalyze > Correlate > Bivariateตัวแปรตัวเลข 2 ตัวขึ้นไปPearson Correlation, Sig.

                
ปัจจัยใดช่วยทำนายยอดขาย/กำไรAnalyze > Regression > Linearตัวแปรตามเป็นตัวเลขR Square, ANOVA Sig., Coefficients

              
            

          

        


        

          

            
ตัวอย่าง SPSS Syntax สำหรับไฟล์จากเว็บนี้

            
* 1) เปิดไฟล์ CSV ที่ Export จากระบบนี้.
GET DATA
  /TYPE=TXT
  /FILE='sample_sales.csv'
  /ENCODING='UTF8'
  /DELCASE=LINE
  /DELIMITERS="," 
  /QUALIFIER='"'
  /ARRANGEMENT=DELIMITED
  /FIRSTCASE=2
  /VARIABLES=
    order_id A20
    order_date A10
    customer_id A20
    customer_name A80
    product_id A20
    category A40
    product_name A80
    region A40
    channel A40
    quantity F8.0
    unit_price F12.2
    discount F8.4
    cost F12.2
    order_status A30
    gross_sales F12.2
    discount_amount F12.2
    net_sales F12.2
    total_cost F12.2
    profit F12.2
    exclude_from_analysis F1.0.
EXECUTE.

* 2) ดูภาพรวม.
FREQUENCIES VARIABLES=category region channel order_status.
DESCRIPTIVES VARIABLES=net_sales profit quantity discount /STATISTICS=MEAN STDDEV MIN MAX.

          

          

            
Checklist ก่อนกดวิเคราะห์ใน SPSS

            

              
✓
หัวตารางต้องไม่มีช่องว่างหรือสัญลักษณ์แปลก เช่น ใช้ net_sales แทน Net Sales

              
✓
ตัวเลขต้องเป็น Number/Scale ไม่ใช่ String เช่น net_sales, profit, quantity

              
✓
ตัวแปรกลุ่มต้องกำหนด Measure เป็น Nominal เช่น channel, region, category

              
✓
ถ้ามีข้อมูลผิดหรือ null ให้แก้ในเว็บนี้ก่อน หรือใช้ Select Cases/Filter ใน SPSS

              
✓
อย่าสรุปจาก p-value อย่างเดียว ให้ดูขนาดผล, ค่าเฉลี่ย, และบริบทธุรกิจร่วมด้วย
