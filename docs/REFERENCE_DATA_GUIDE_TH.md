# คู่มือข้อมูลอ้างอิงและการแก้ไขข้อมูล

หน้านี้เพิ่มมาเพื่อช่วยผู้ใช้ที่ไม่เคยใช้ SQL มาก่อนให้เข้าใจข้อมูลระดับ `customer_id` และ `product_id` ได้ง่ายขึ้น

## หน้านี้ใช้ทำอะไร

1. ดูว่า `customer_id` คือใคร เช่น ชื่อลูกค้า จังหวัด ภูมิภาค ยอดซื้อรวม และวันที่ซื้อล่าสุด
2. ดูว่า `product_id` คือสินค้าอะไร เช่น ชื่อสินค้า หมวดสินค้า ยอดขาย กำไร และ Profit Margin
3. ตรวจแถวที่มีค่าว่างในคอลัมน์สำคัญ เช่น customer, product, date, sales
4. แก้ไขข้อมูลผิดโดยไม่ต้องเขียน SQL
5. ทำเครื่องหมาย “ไม่นำแถวนี้ไปคำนวณ” หากข้อมูลยังไม่ถูกต้องหรือรอตรวจสอบ

## วิธีใช้งาน

1. สร้างข้อมูลตัวอย่างหรือ Import CSV ก่อน
2. เปิดแท็บ **ข้อมูลอ้างอิง/แก้ไขข้อมูล**
3. เลือกตารางข้อมูลหลัก เช่น `sales_data` หรือ `uploaded_data_completed`
4. ดูตาราง Customer Reference และ Product Reference
5. หากต้องการเก็บตารางอ้างอิงไว้ในฐานข้อมูล ให้กด **สร้างตารางอ้างอิงลูกค้า/สินค้า**
6. ถ้าพบแถวผิดหรือค่าว่าง ให้กด **แก้ไข** ที่ Data Review Queue หรือ Table Browser
7. แก้ไขค่าแล้วกด **บันทึกการแก้ไข**
8. หากไม่ต้องการนำแถวนั้นไปคำนวณ ให้ติ๊ก **ไม่นำแถวนี้ไปคำนวณ Dashboard / Business Analytics**

## คอลัมน์ที่ระบบเพิ่มให้

ระบบจะเพิ่มคอลัมน์ควบคุมคุณภาพข้อมูลให้ตารางที่แก้ไขได้:

| คอลัมน์ | ความหมาย |
|---|---|
| `_exclude_from_analysis` | 0 = ใช้คำนวณ, 1 = ไม่ใช้คำนวณ |
| `_exclude_reason` | เหตุผลที่ไม่นำแถวนี้ไปคำนวณ |
| `_last_updated_at` | เวลาล่าสุดที่มีการแก้ไขผ่านหน้าเว็บ |

Dashboard และ Business Analytics จะไม่เอาแถวที่ `_exclude_from_analysis = 1` ไปคำนวณ

## ข้อควรระวัง

- การแก้ไขข้อมูลในเว็บนี้แก้ไขฐานข้อมูล SQLite ที่อยู่ใน browser เท่านั้น
- หากต้องการเก็บการแก้ไขไว้ ต้องกด **บันทึก .db** หรือ Export CSV
- ถ้าเลือกตารางที่เป็น View จะดูข้อมูลได้ แต่แก้ไขโดยตรงไม่ได้ ให้เลือกตารางจริงแทน
- ก่อนใช้กับข้อมูลจริง ควรสำรองไฟล์ต้นฉบับทุกครั้ง
